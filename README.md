# Práctica de Git y GitHub

Repositorio de práctica para aprender control de versiones y documentar casos de prueba.

## Objetivo

Practicar Git y GitHub para documentar casos de prueba y prepararme para automatización con Playwright.

## Alcance de la práctica

- Documentación de casos de prueba.
- Control de versiones con Git.
- Publicación y colaboración mediante GitHub.

## Estado del repositorio

Repositorio publicado en GitHub con flujo de ramas y Pull Requests praticado.
